# Source structure and image-policy validation

The current scripts passed 36 integrated acceptance programs and 173 unittest cases. Tests cover exact `[IMAGE]`, source identity/captions/table cells, SVG/CSS/picture contexts, recursive metadata, no separate image acquisition, and no image decoding in the new footnote/list cases. The source snapshot and runtime remained unchanged throughout.

The actual normalized Flagstaff and Boston outputs separately pass the image audit. The frozen evidence package contains 1,870 files and no separate image binaries. Counts of placeholders across serialized fields are diagnostic and are not counts of unique source images. Native originals may embed images and remain immutable.
