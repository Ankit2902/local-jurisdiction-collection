Code Enforcement & Compliance

Report a Code Violation

Do you need to report an eyesore? Let the City of Orlando know about code violations within city limits.

Pay a Code Enforcement Fine

If you received a fine for a code enforcement violation, you can view how much you owe and instructions on how to pay your balance.

Look Up Code Enforcement Cases and Liens

Look up a code enforcement incident by incident number or address to see the latest status of a complaint.

Look Up City Codes

Search the City of Orlando Municipal Codes.

Resolve a Code Enforcement Issue Related to Permitting Compliance

You will need to get the appropriate permits for unapproved construction work or business operations.

Get Help With an Issue Not Covered by Code Enforcement

The City of Orlando offers resources to help with housing and neighborhood issues not covered by Code Enforcement.

Register a Responsible Person for Your Business

Every business selling alcohol after midnight within the Downtown Entertainment Area must identify a Responsible Person in charge of the establishment at that time. Each Responsible Person must register with the Code Enforcement Division and must remain on-site during all operations until closing.
