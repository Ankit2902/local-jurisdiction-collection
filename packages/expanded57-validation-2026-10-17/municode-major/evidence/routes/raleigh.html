City Code

Updated: Mar 10, 2026

Jump To:

 
Municode

The City Code for the City of Raleigh serves as the laws of the city. The City Code started in 1792 when the City of Raleigh was first chartered. The Code is adopted by the City Council and can only be changed by the City Council.  There are an average of 5 code changes during each City Council meeting.

Municode

The City contracts with the Municipal Code Corporation to maintain and update the code when changes occur. Part of the City's contract makes the Code available for staff and citizens through the Municode web interface.
