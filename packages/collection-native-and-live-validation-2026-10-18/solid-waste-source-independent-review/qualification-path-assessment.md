# Read-only qualification-path assessment pending frozen source candidate

The reviewed exact source revisions are bound in `shared-path-source-binding.json`; this assessment changes no runtime, catalog, scope, acceptance or evidence files.

`native_document.page_records()` currently measures native character/word ownership and detector cells. It deliberately sets `pdf_table_semantics_complete=false` and `reading_order_manual_review_required=true`. `verify()` replays exact start/end bytes, receipts, selected config, page count and serialized outputs, then explicitly returns publication text, attachments, edition and jurisdiction completeness false. A complete file/page capture cannot currently pass the common publication acceptance gate.

`ops.launcher.publication_acceptance()` separately reads publication text and required-document completion and consumes native `pdf_details.pdf_table_semantics_complete`. Required PDF integrity-map entries also require their own text/table qualifications; parent HTML and native binary integrity do not supply them. The source-specific six-page proof therefore needs a measured native summary and narrow coverage mapping, not a generic true default or exit-code override.

Before any source-specific promotion, the frozen actual-source evidence should establish all of the following for the exact PDF SHA, observed URL, six physical pages and selected publication identity:

- Complete source structure/ParentTree/MCID binding; all nonartifact native glyphs and source text spans have exactly one canonical logical owner, with no omitted/duplicated text.
- Source heading hierarchy, list item ordering and continuations, paragraph/section boundaries and cross-page ordering are preserved. Ambiguities and source artifacts have explicit dispositions.
- Canonical JSON and the operational CSV consume the selected logical text/order, rather than a parallel alternate proof. Exact prior detector fields remain recoverable diagnostics.
- Table applicability is source-proven. A source-specific no-table disposition needs evidence for the actual complete document and must not become a generic inference from empty detector output or tags alone.
- Required embedded/external document references are inventoried and qualified separately. A heading/tree proof cannot silently set attachments complete.
- All source controls and negative mutations refuse changed bytes, source/object/tag/MCID ownership, canonical order/text, missing pages, false metadata, stale exports and unsupported profiles.
- No image fetch/read/decode/extract/render/OCR path is used. Native image occurrence positions remain literal `[IMAGE]` with metadata-only ownership, or source-proven zero occurrences.

Useful measured fields would distinguish source text conservation, logical structure/heading/list/order fidelity, artifact disposition, table applicability/structure, remaining ambiguities and required-document inventory. Field names should match the frozen producer's actual measurements before integration. Only an exact source profile with all necessary dimensions proved could map its selected native document's text/structure to true. Generic PDFs retain their current conservative defaults. File integrity, source/tag capture, character conservation, normalized source structure and legal interpretation/edition/adoption are separate claims; this review proposes no edition/adoption/jurisdiction promotion.

The six-page retained-source review will not itself establish a new live edition/currentness check. Existing opening/closing and source acquisition provenance must remain bound, and any currentness limitation stays explicit.
