Code of Ordinances

The Code of Ordinances codifies certain ordinances that are of a general or permanent nature. The Metropolitan Council adopts many ordinances and resolutions that are not included in the Code of Ordinances. All ordinances and resolutions are public records and are on file and available in the Council Administrator-Treasurer’s Office. Please contact the Council Administrator-Treasurer’s Office at 389-3123 or Email Council Administration for additional information. To view the Code of Ordinances, visit the Code of Ordinances.
