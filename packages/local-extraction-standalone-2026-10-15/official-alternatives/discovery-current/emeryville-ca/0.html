Building Division

As part of the Community Development Department, the Building Division has primary responsibility for administering the laws, regulations, and requirements that pertain to the physical development of the City.

The Building Division provides code administration, plan review and field inspections of buildings to ensure a safe, accessible, and energy efficient environment throughout the community. The division regulates local and State laws related to building construction, maintenance, use, repair, and rehabilitation.

Other Federal and State requirements include the mandated accessibility and energy conservation statutes. These objectives are accomplished through administration of public outreach and technical assistance programs, as well as building code regulation.

Important Notices

The Adopted Building Codes will be in effect January 1, 2026 as follows:

  • 2025 California Building Code Part 2; Volume 1 and 2
  • 2025 California Residential Code
  • 2025 California Green Building Standards Code
  • 2025 California Mechanical Code
  • 2025 California Plumbing Code
  • 2025 California Energy Code
  • 2025 California Electrical Code
  • 2025 California Fire Code

For information regarding the California Building Code or Emeryville Municipal Code, contact the Building Division 510-596-4310 or cbarrett@emeryville.org

All new building permit submittals received on or after 12:00 a.m. on January 1, 2026 must comply with the 2025 California Building Standards Code (Title 24). No applications submitted on or after this date will be accepted under the 2022 code cycle.
 
Definition of a Complete Application
A complete application must include:
• Fully completed permit application
• Required construction documents
• Required calculations and supporting documents
• Applicable plan review fees paid
 

Amendments

It should be noted that the above codes have been amended by the State of California and the City of Emeryville (Emeryville Municipal Code Title - 8(PDF, 537KB)) to include various additional requirements based on local conditions.

 

Building & Fire Permits & Programs

Building permits are required for most construction and repair work. Apply for a building and fire permit.

Code Enforcement

The Code Enforcement Division works to ensure that residential and commercial properties throughout the city are maintained in a safe, sanitary, and orderly condition.

Smoke-Free Multi-Unit Housing

The Emeryville Smoking Pollution Ordinance prohibits smoking in multi-unit housing and at public events, hotels, and other areas. Learn more about compliance and designated smoking areas.
